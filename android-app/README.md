# Отчёт: заборы (Android)

Приложение для фотоотчётов о ремонте металлических заборов (Кокшетау).

## Как работает
1. Запуск → сразу открывается камера. Внизу видны текущие GPS-координаты и точность.
2. Кнопка съёмки активна, когда есть координаты.
3. После снимка открывается экран разметки: нажмите на место сварки — появится
   маркер (красное кольцо с номером). Маркеров может быть несколько, их можно
   перетаскивать, «Убрать маркер» удаляет последний.
4. «Сохранить» → фото попадает в галерею, альбом `Pictures/FenceReports`.

## Что в фото
- Внизу плашка: координаты (±точность), дата/время, ссылка на 2ГИС.
- Маркеры сварки нарисованы на фото.
- EXIF: GPS-координаты (и высота), дата съёмки,
  `ImageDescription` = ссылка 2ГИС, `UserComment` = ссылка + число маркеров.

Ссылка вида `https://2gis.kz/kokshetau/geo/<долгота>,<широта>`.

> Мессенджеры (WhatsApp, Telegram «как фото») обычно удаляют EXIF.
> Поэтому ссылка и координаты ещё и напечатаны на самом фото. Чтобы метаданные
> сохранились, отправляйте файлом/документом.

## Сборка
APK собирается GitHub Actions (`.github/workflows/android.yml`) при каждом пуше
и публикуется в Releases (`FenceReport.apk`).

Локально: открыть папку `android-app` в Android Studio или `./gradlew assembleRelease`.

Требования: Android 8.0+, камера, GPS, Google Play Services.
